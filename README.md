# Agricultural Land Classifier

Keras and PyTorch notebooks for classifying agricultural and non-agricultural land from satellite images.

## Tools

- TensorFlow / Keras
- PyTorch / torchvision
- scikit-learn
- matplotlib

## Flow

1. Compare data loading methods
2. Build data loading and augmentation pipelines
3. Train Keras and PyTorch CNN models
4. Compare both models using classification metrics and ROC curves
5. Build CNN-Vision Transformer models
6. Evaluate the final Keras and PyTorch models

## Results

- Keras CNN Accuracy: 95.92%
- PyTorch CNN Accuracy: 99.06%
- Keras CNN-ViT Accuracy: 99.58%
- PyTorch CNN-ViT Accuracy: 99.90%

## Run

Open the notebooks in Jupyter and follow them from Module 1 to Module 4.
